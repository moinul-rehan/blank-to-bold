# Blank to Bold

An award-level, story-driven interactive experience presenting Rehan's
journey as a Product Designer — a digital product, not a portfolio site.

See [CLAUDE.md](./CLAUDE.md) for project principles and [docs/](./docs) for
the full knowledge base (vision, brand, experience, design principles, tech
stack, architecture, coding standards, motion language, and roadmap).
Current status is tracked in [CONTEXT.md](./CONTEXT.md).

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui · GSAP · Lenis ·
Zustand · MDX · Lucide

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — production build
- `pnpm start` — run the production build
- `pnpm lint` — lint
- `pnpm format` — format with Prettier
