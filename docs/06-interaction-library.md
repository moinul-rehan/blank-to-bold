# 06 — Interaction Library

> **Status: not yet started.** This doc will catalog every reusable
> interaction pattern in the project as they're built, so nothing gets
> reinvented or duplicated.

## Purpose

Every interaction in the product should become a named, documented, reusable
entry here — not a one-off. Before building a new interaction, check this
list first.

## Entry template

```
### <Interaction name>

- **Where it's used:** which feature(s) in `src/features/`
- **Why it exists:** the answer to "why does this exist?"
- **Trigger:** hover / click / scroll / load / etc.
- **Implementation:** which system/animation/component it lives in
- **Reduced-motion behavior:** what happens when the user prefers reduced motion
```
